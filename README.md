# ایجنت ویس فارسی

تبدیل گفتار فارسی به متن — هم زنده از میکروفون، هم از روی فایل صوتی.
کاملاً داخل مرورگر اجرا می‌شود. بدون Node، بدون Python، بدون نصب هیچ چیزی.

---

## راه‌اندازی

روی `serve.ps1` راست‌کلیک کنید و **Run with PowerShell** را بزنید.
مرورگر خودش روی `http://localhost:8787` باز می‌شود.

اگر ویندوز اجازه نداد، در PowerShell این را بزنید:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

### چرا با دابل‌کلیک روی index.html کار نمی‌کند؟

مرورگرها روی نشانی `file://` اجازهٔ دسترسی به میکروفون نمی‌دهند. بدون سرور محلی،
بخش **گفتار زنده** کار نخواهد کرد. بخش **فایل صوتی** با دابل‌کلیک هم کار می‌کند.

---

## دو بخش، دو موتور متفاوت

| | گفتار زنده | فایل صوتی |
|---|---|---|
| موتور | تشخیص گفتار خودِ مرورگر | مدل هوش مصنوعی از راه OpenRouter |
| هزینه | رایگان و بدون سقف | نیازمند اعتبار حساب |
| کلید API | لازم ندارد | لازم دارد |
| اینترنت | لازم دارد | لازم دارد |
| مرورگر | فقط Edge و Chrome | همه |
| وضعیت | **آماده استفاده** | **نیازمند شارژ حساب** |

### گفتار زنده

دکمهٔ میکروفون را بزنید و فارسی حرف بزنید. متن هم‌زمان نوشته می‌شود.
پس از توقف، متن قابل ویرایش می‌شود و می‌توانید رونوشت بگیرید، در فایل ذخیره کنید،
یا صدای ضبط‌شده را نگه دارید.

این بخش از `SpeechRecognition` مرورگر استفاده می‌کند. توجه داشته باشید که در این
حالت، مرورگر صدا را برای پردازش به سرورهای مایکروسافت (در Edge) یا گوگل (در Chrome)
می‌فرستد. اگر محتوای گفتگو حساس است، این را در نظر بگیرید.

### فایل صوتی — و محدودیتی که باید بدانید

**آزمایش شد و تأیید شد:** OpenRouter ارسال صدا را برای حساب‌های با موجودی صفر
مسدود می‌کند و این خطا را برمی‌گرداند:

```
HTTP 402 — This request requires at least $0.50 in balance for audio
```

این محدودیت:

- به مدل ربطی ندارد — حتی تنها مدل رایگانِ صوتی
  (`nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`) هم مسدود است
- به حجم فایل ربطی ندارد — فایل دو ثانیه‌ای هم همین خطا را گرفت
- در مستندات OpenRouter نوشته نشده است

در مقابل، مدل‌های **متنی** رایگان با همان حساب صفر بدون مشکل کار می‌کنند
(همین است که دکمهٔ «ویرایش و نقطه‌گذاری» رایگان کار می‌کند).

**برای فعال کردن این بخش** کافی است حساب OpenRouter را شارژ کنید. هیچ تغییری در
کد لازم نیست — فقط کلید را در تنظیمات وارد کنید. برای سنجیدن هزینه:
`google/gemini-2.5-flash-lite` صدا را حدود **۳.۵ سنت برای هر ساعت** حساب می‌کند،
یعنی ۵ دلار تقریباً ۱۴۰ ساعت رونویسی است.

## کلید API

در زبانهٔ **تنظیمات** وارد می‌شود و فقط در `localStorage` مرورگر خودتان می‌ماند.

این اپ سروری ندارد و هیچ کلیدی داخل کدش نیست و نباید باشد — هر چیزی که داخل فایل
HTML بنشیند، با F12 برای همه قابل خواندن است. به همین دلیل هر کاربر کلید خودش را
وارد می‌کند.

هنگام ساخت کلید در [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys)
حتماً یک **Credit limit** تعیین کنید تا سقف ضرر مشخصی داشته باشد.

دکمهٔ «بررسی اعتبار» در تنظیمات وضعیت حساب، مصرف و تاریخ انقضای کلید را نشان می‌دهد.

## ساختار

بدون هیچ وابستگی بیرونی. هیچ CDN، هیچ کتابخانه‌ای. اسکریپت‌های کلاسیک (نه ماژول)،
چون ماژول‌های ES روی `file://` مسدودند. همه‌چیز روی فضای نام `App` می‌نشیند.

ترتیب بارگذاری یک گراف وابستگی واقعی است و نباید به هم بخورد:

```
config → util → store → audio → openrouter → transcribe → live → ui → app
```

| فایل | نقش |
|---|---|
| `config.js` | تنظیمات پیش‌فرض، نام مدل‌ها، متن دستورها |
| `util.js` | ساخت DOM، شکل‌دهی عدد فارسی، دانلود فایل |
| `store.js` | ذخیره در localStorage: کلید، تنظیمات، بایگانی |
| `audio.js` | رمزگشایی صدا، تبدیل به WAV تک‌کاناله ۱۶ کیلوهرتز، برش، base64 |
| `openrouter.js` | کلاینت API، مدیریت خطا، تلاش دوباره، کنترل سقف نرخ |
| `transcribe.js` | هماهنگی رونویسی فایل و دوختن تکه‌های هم‌پوشان |
| `live.js` | گفتار زنده با Web Speech API + ضبط موازی صدا |
| `ui.js` | همهٔ نماها و فرم‌ها. تنها ماژولی که DOM را در دست دارد |
| `app.js` | راه‌اندازی |

### چند تصمیم که عمدی‌اند

**تبدیل به WAV اجباری است.** OpenRouter فقط `wav` و `mp3` می‌پذیرد، آن هم base64.
ولی `MediaRecorder` مرورگر خروجی `webm/opus` می‌دهد و فایل‌های کاربر معمولاً
`m4a` یا `ogg` هستند. پس هر ورودی از مسیر `decodeAudioData` رد و به WAV تبدیل می‌شود.

**تکه‌ها هم‌پوشان‌اند.** دو ثانیه همپوشانی می‌گذاریم تا کلمهٔ لبِ برش دو نیم نشود،
بعد در `transcribe.stitch()` بلندترین تکرار تا ۱۲ کلمه پیدا و حذف می‌شود.

**وضعیت هرگز فقط با رنگ گفته نمی‌شود.** هر نشان وضعیت، نقطه و متن هم دارد.

**سه حالت پوسته، نه دو:** روشن، تاریکِ سیستم، و انتخاب صریح کاربر. رنگی که فقط
داخل `@media` یا `[data-theme]` تعریف شود، در حالت بی‌نشان اعمال نمی‌شود.

**اعداد داخل `.num` می‌روند** تا علامت منفی یا `٪` داخل متن راست‌به‌چپ جابه‌جا نشود.

## نکتهٔ ویرایش فایل‌ها

`serve.ps1` باید **UTF-8 با BOM** ذخیره شود. PowerShell 5.1 فایل‌های `.ps1` بدون BOM
را با کدپیج ANSI می‌خواند و متن فارسی داخلشان خرد می‌شود و اسکریپت اصلاً پارس نمی‌شود.
بقیهٔ فایل‌ها UTF-8 بدون BOM هستند.
